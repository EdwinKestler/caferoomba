# Dataset

Records follow `caferoomba.record.v1`. Missing GNSS/heading/velocity is omitted,
never filled with zero.

- Only `viewpoint=FPV` may enter an FPV policy set. `EXTERNAL` is rejected.
- `SYNTHETIC` fixtures are labeled `is_synthetic: true` and are not FPV.
- Clip windows end at `decision_timestamp_ms`. Future frames are invalid.
- Operator vs video PTS deltas above tolerance raise `SyncError`.
- Splits are by whole `run_id`. Leakage is a failed test.

No authorized FPV demonstration files were present in this checkout (chat
uploads are not local paths; `docs/videos/` is gitignored and unused).

CPU smoke data is generated by `caferoomba.data.fixtures.build_synthetic_clips`.
